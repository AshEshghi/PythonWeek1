# Python Week 1

Solutions for the four Week 1 tasks in the Compact Programming Course: Python.

| File | Task |
| --- | --- |
| `main.py` | Task 1 — area of a circle |
| `task2.py` | Task 2 — simple variable declaration and output |
| `task3.py` | Task 3 — data type conversion |
| `task4.py` | Task 4 — factorial |

Run each program with Python 3:

```bash
python main.py
python task2.py
python task3.py
python task4.py
```

On some systems, use `python3` instead of `python`.
