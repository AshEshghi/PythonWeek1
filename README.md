# Compact Programming Course: Python
FH Dortmund Digital Transformation

Python exercises and assignments for the Compact Programming Course at FH Dortmund.

## Week 1

- Task 1: Calculate the area of a circle
- Task 2: Simple variable declaration and output
- Task 3: Data type conversion
- Task 4: Factorial calculation

## Week 2

- Task 1: Sort a list of tuples by the last element
- Task 2: Calculate the sum and average of digits in a string
- Task 3: Sort a list of dictionaries using lambda
- Task 4: Convert a list of strings into a list of lists using `map()`
- Task 5: Store and filter Dortmund events using a dictionary
